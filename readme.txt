== Description ==

WooBot enables e-commerce store owners to upload products to their WooCommerce store by sending a product photo via WhatsApp. Using AI-powered image analysis, WooBot automatically extracts product details like name, price, and description.

**Key Features:**

* Upload products via WhatsApp — just send a photo
* AI-powered image analysis extracts product data automatically
* Optional AI image enhancement for better product photos
* Secure REST API for external integrations
* Admin dashboard with usage stats and logs
* Quick-access dashboard button in WordPress admin bar
* Rate limiting and security built-in
* RTL and Hebrew language support
* Credit-based usage model

**How It Works:**

1. Site builder installs WooBot on client's WooCommerce store
2. Plugin generates a unique Store Key and WhatsApp link
3. Store owner clicks the link and starts a WhatsApp conversation
4. Store owner sends product photos — AI handles the rest
5. Products appear in WooCommerce, ready for review

== Installation ==

1. Upload the `woobot-whatsapp-uploader` folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to WooCommerce → WooBot to configure
4. Copy the Store Key and WhatsApp link
5. Share the WhatsApp link with the store owner
